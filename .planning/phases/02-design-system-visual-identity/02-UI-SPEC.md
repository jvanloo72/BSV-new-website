## Color Tokens

Locked values (D-01). Light mode only (D-04). All hex set; `--color-bg-elevated` resolved from discretion.

| Token (`@theme`) | Value | Role (60/30/10) | Generates utilities |
|------------------|-------|-----------------|---------------------|
| `--color-bg` | `#F8F5F0` | **Dominant (~60%)** — warm off-white page background, body, hero ground | `bg-bg`, `text-bg`, `border-bg` |
| `--color-bg-elevated` | `#FDFCFA` **[discretion — locked]** | **Secondary (~30%)** — near-white floating card/surface fill (cards, accordion panels, fee band); lighter than the page so soft shadow reads as "floating" (D-09) | `bg-bg-elevated` |
| `--color-text` | `#111111` | Body + heading text on `bg`/`bg-elevated` | `text-text` |
| `--color-text-muted` | `#52524E` | Graphite — secondary copy, labels, captions, eyebrows, metadata | `text-text-muted` |
| `--color-border` | `#D9D2C5` | Warm-grey hairline borders/dividers on cards & sections (decorative, paired with shadow) | `border-border`, `divide-border` |
| `--color-accent` | `#9A3F1A` | **Accent (~10%)** — deep rust / persimmon (D-02) | `text-accent`, `bg-accent`, `ring-accent`, `fill-accent`, `stroke-accent` |
| `--color-accent-fg` | `#F8F5F0` | Foreground ON the accent (button label text on rust fill) | `text-accent-fg` |

### Color split (60/30/10)
- **60% Dominant:** `#F8F5F0` page background — the quiet warm-off-white ground that dominates every viewport.
- **30% Secondary:** `#FDFCFA` floating surfaces — cards, FAQ panels, fee band, attorney/practice cards — visually distinguished from the page only by being slightly lighter + the soft warm shadow.
- **10% Accent:** `#9A3F1A` deep rust, **reserved for** (the explicit list — never "all interactive elements"):
  1. Primary CTA button fill (`CtaBlock` button, Hero primary button)
  2. Text links in body copy + the animated link underline (D-10)
  3. The hero converging-linework SVG stroke (D-12) and the 3 practice-area icons (D-13) via `currentColor`
  4. The Chambers USA Spotlight 2026 recognition strip emphasis (LEGAL-07)
  5. `:focus-visible` rings on every interactive element (A11Y-05)
  6. Small accent details: testimonial open-quote glyph, fee-band leading marker, active-nav indicator
- **No second semantic (destructive) color this phase.** Phase 2 ships zero destructive actions (no forms, no delete/remove anything). Destructive/error palette is introduced in Phase 6 (contact form). Recorded as N/A here.

### WCAG contrast — all pairings computed (A11Y-04, hard requirement)
Computed via WCAG 2.1 relative-luminance formula on the locked hexes (2026-05-26):

| Pairing | Ratio | AA normal (4.5:1) | AA large/UI (3:1) | Verdict |
|---------|-------|-------------------|-------------------|---------|
| `text` `#111111` on `bg` `#F8F5F0` | **17.36:1** | ✅ | ✅ | AAA |
| `text-muted` `#52524E` on `bg` `#F8F5F0` | **7.22:1** | ✅ | ✅ | AAA (passes normal-text) |
| `text` `#111111` on `bg-elevated` `#FDFCFA` | **18.42:1** | ✅ | ✅ | AAA |
| `text-muted` `#52524E` on `bg-elevated` `#FDFCFA` | **7.65:1** | ✅ | ✅ | AAA |
| `accent` `#9A3F1A` on `bg` `#F8F5F0` (link/icon text) | **6.23:1** | ✅ | ✅ | AAA |
| `accent` `#9A3F1A` on `bg-elevated` `#FDFCFA` | **6.61:1** | ✅ | ✅ | AAA |
| `accent-fg` `#F8F5F0` on `accent` `#9A3F1A` (button label) | **6.23:1** | ✅ | ✅ | AAA |
| `border` `#D9D2C5` on `bg` `#F8F5F0` | 1.38:1 | n/a | n/a | **Decorative non-text — acceptable** |

- Every text/icon/button pairing clears **AA and AAA**. No pairing fails → no discretion hex needs adjustment. `#FDFCFA` is **locked** for `bg-elevated` (passes all three text checks against it).
- Note on `accent/bg` = 6.23:1: this is slightly below the ~6.8:1 Jon cited in D-02 (the cited figure was an estimate), but comfortably exceeds AA (4.5:1) and AAA (7:1 is AAA-normal — 6.23 is AAA for *large* text and AA for normal; for link text at body size it is **AA-compliant**, which satisfies A11Y-04). No action required.
- `border/bg` at 1.38:1 is intentional and acceptable: the border is decorative trim that never carries meaning or state on its own — the soft shadow (D-09) provides the actual figure/ground separation. WCAG 1.4.11 (3:1 UI contrast) applies to components whose *boundary conveys information*; these card borders do not. **Do not darken the border to chase a ratio** — it would break the premium-quiet aesthetic (D-08).

## Typography

**One typeface, hierarchy from size + weight + spacing (D-05/D-08).** Fluid `clamp()` scale so headlines are dramatic on desktop and controlled on mobile. Weights committed: **400 / 500 / 700 / 800** (a single variable woff2 preferred if ≤ ~100 KB — see Asset Budget). `font-display: swap` + Astro-generated `size-adjust` fallback metrics keep CLS ≤ 0.1 (PERF-05).

### `@theme` type tokens **[discretion — locked clamp stops]**

| Token | `clamp(min, preferred, max)` | px range (16px root) | Weight | Line-height | Letter-spacing | Role |
|-------|------------------------------|----------------------|--------|-------------|----------------|------|
| `--text-display` | `clamp(2.75rem, 1.6rem + 5.75vw, 5rem)` | 44 → 80px | **800** | **1.05** | -0.02em | Hero H1 only — the one "big and bold" moment (D-08) |
| `--text-h1` | `clamp(2.25rem, 1.6rem + 3.25vw, 3.5rem)` | 36 → 56px | **700** | **1.1** | -0.015em | Page-level H1 (non-hero pages) |
| `--text-h2` | `clamp(1.75rem, 1.4rem + 1.75vw, 2.5rem)` | 28 → 40px | **700** | **1.15** | -0.01em | Section headings |
| `--text-h3` | `clamp(1.3125rem, 1.15rem + 0.8vw, 1.625rem)` | 21 → 26px | **700** | **1.2** | -0.005em | Card titles (PracticeAreaCard, AttorneyCard), FAQ questions |
| `--text-body-lg` | `1.1875rem` (19px, static) | 19px | 400 | **1.6** | 0 | Hero subhead, lead paragraphs, pull-quote body |
| `--text-body` | `1.0625rem` (17px, static) | 17px | 400 | **1.6** | 0 | Default body copy |
| `--text-small` | `0.875rem` (14px, static) | 14px | 500 | 1.5 | 0.01em | Eyebrows, labels, captions, fee-band fine print, metadata |

- **Body line-height 1.6** (generous, whitespace-forward, DESIGN-07); **heading line-height 1.05–1.2** (tight for drama, D-08). Tighter negative tracking on the largest sizes only — standard for big grotesque display.
- Weight discipline: body = **400**, labels/small = **500**, all headings = **700**, hero display = **800**. Medium (500) is the only "in-between" weight; do not introduce 600 or 300.
- `--font-sans` references the Fonts API variable: `--font-sans: var(--font-hanken), ui-sans-serif, system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;` — so existing Phase 1 components using `font-sans` adopt Hanken automatically.
- Min sizes never drop below 14px (small) / 17px (body) on mobile (A11Y / readability). Headings degrade gracefully via the clamp min.

## Spacing Scale

**[discretion — locked]** Base unit **4px**, generous whitespace-forward rhythm (DESIGN-07). Standard scale maps to Tailwind's default spacing (which is already 4px-based, so `p-4`=16px etc. work out of the box). The phase adds **named section-rhythm tokens** in `@theme` for the big vertical breathing room between page sections.

Standard step scale (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, inline chip padding |
| sm | 8px | Compact element spacing, tag gaps |
| md | 16px | Default element spacing inside cards |
| lg | 24px | Card interior padding (mobile), stack gaps |
| xl | 32px | Card interior padding (desktop), component internal blocks |
| 2xl | 48px | Gaps between cards in a grid, sub-section breaks |
| 3xl | 64px | Minor section spacing |

Named fluid rhythm tokens (added to `@theme`):

| Token | `clamp()` value | px range | Generates | Usage |
|-------|-----------------|----------|-----------|-------|
| `--spacing-section` | `clamp(4rem, 2.5rem + 7vw, 8rem)` | 64 → 128px | `py-section`, `gap-section`, `mt-section` | Vertical padding between major page sections (the "generous whitespace" signature) |
| `--spacing-gutter` | `clamp(1.25rem, 0.75rem + 2vw, 2rem)` | 20 → 32px | `px-gutter` | Page side gutters (mobile→desktop) |

- Max content width: **`max-w-6xl` (72rem / 1152px)** centered (`mx-auto`) — matches the existing Phase 1 header/footer container so chrome and content align.
- A narrower **`max-w-3xl` (48rem)** measure for long-form prose (about page, testimonial blocks) to keep line length ~65–75ch for readability.
- **Touch targets:** every interactive control (buttons, nav links, FAQ summary, card links) has a minimum hit area of **44×44px** (A11Y / WCAG 2.5.5) — enforce via padding, not fixed height, so text can wrap.

Exceptions: the 44px touch-target minimum is the only "non-step" constraint (it's a floor, not a scale value). Hairline borders are 1px (sub-base, standard).

### Radius & Shadow tokens **[discretion — locked]**

| Token | Value | Generates | Usage |
|-------|-------|-----------|-------|
| `--radius-card` | `0.75rem` (12px) | `rounded-card` | Cards, accordion panels, fee band, buttons use a tighter `rounded-lg` |
| `--radius-button` | `0.5rem` (8px) | `rounded-button` | Buttons |
| `--shadow-card` | `0 1px 2px rgba(60,30,15,0.04), 0 8px 24px -4px rgba(60,30,15,0.06)` | `shadow-card` | Soft, **warm-tinted** (rust-black, low opacity) floating shadow (D-09) — subtle, premium, not SaaS-generic |
| `--shadow-card-hover` | `0 2px 4px rgba(60,30,15,0.05), 0 16px 36px -6px rgba(60,30,15,0.10)` | `shadow-card-hover` | Deepened shadow on card hover-lift (D-10), motion-safe only |

The shadow tint uses `rgba(60,30,15,...)` (a dark warm brown) rather than neutral black so it harmonizes with the warm `#F8F5F0` ground — this is what keeps it reading "premium boutique" not "generic dashboard."

## Motion & Interaction Contract (D-10)

All micro-interactions are **restrained** and **gated behind `prefers-reduced-motion`**. Mechanism: Tailwind `motion-safe:` variant on component utilities (maps to `@media (prefers-reduced-motion: no-preference)`), backstopped by a global `@media (prefers-reduced-motion: reduce){ *,::before,::after{animation:none!important;transition:none!important;scroll-behavior:auto!important} }` guard in `global.css`. **Zero client JS** — pure CSS.

| Interaction | Element | Effect | Implementation | Reduced-motion behavior |
|-------------|---------|--------|----------------|-------------------------|
| Card hover-lift | PracticeAreaCard, AttorneyCard, DealsGrid cell | translateY(-4px) + shadow deepen | `transition-transform transition-shadow duration-200 ease-out motion-safe:hover:-translate-y-1 motion-safe:hover:shadow-card-hover` | No transform/shadow change; instant |
| Animated link underline | Body/text links | underline grows left→right on hover | `relative` link + `after:` pseudo (`after:h-px after:w-0 after:bg-accent motion-safe:after:transition-[width] hover:after:w-full`) | Underline present statically (always visible for links so reduced-motion users still see affordance) |
| Button hover-deepen | Primary/secondary buttons | fill darkens (`bg-accent` → ~90% / darker rust) | `transition-colors duration-150 motion-safe:hover:bg-[#822F12]` (or `hover:bg-accent/90`) | Color still changes (color change is not motion); transition just becomes instant |
| FAQ smooth expand | FaqAccordion `<details>` | content height animates open/closed | native `<details>` + CSS `interpolate-size: allow-keywords` / `transition: grid-template-rows` on a wrapper; `motion-safe:` gated | Snaps open/closed instantly; full content still reachable |

- **Focus states (A11Y-05):** every interactive element gets a visible `focus-visible` ring in accent: `focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-accent focus-visible:ring-offset-2 focus-visible:ring-offset-bg`. This is **not** gated behind motion (it must always show). Ring offset uses the page bg so it reads on both `bg` and `bg-elevated`.
- **Keyboard operability (A11Y-03):** FaqAccordion uses native `<details>/<summary>` → Enter/Space toggles, Tab focuses, for free. Links/buttons are native `<a>`/`<button>`. No custom key handlers, no `tabindex` hacks.
- Durations: 150–200ms, `ease-out`. Nothing longer (restraint).
